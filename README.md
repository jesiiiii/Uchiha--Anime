# Uchiha Anime

A native Android UI prototype for testing anime browsing screens with mock data only.

## Scope
- Jetpack Compose UI
- Home, Categories, Anime Details, Favorites, and Profile screens
- Local mock content only; no API, database, account system, or real video playback
- GitHub Actions workflow builds a debug APK

## Build
Open this project in Android Studio and run `assembleDebug`, or download the APK from the **Actions** workflow artifact after a successful run.
